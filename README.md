# Smartkid Abacus – Boragaon Centre

A static, single-page website for Smartkid Abacus Boragaon Centre, Guwahati.

Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, Vercel).

## Structure
- `index.html` – page content (hero, about, benefits, mental-math quiz, programs, gallery, reviews, contact)
- `css/style.css` – styles and animations
- `js/main.js` – animated abacus, typing headline, scroll reveals, counters, quiz, lightbox, WhatsApp enquiry form
- `images/` – custom SVG illustrations and logo

## Before going live, confirm with the client
- Weekday batch timings (only "opens 4 PM Saturday" is known)
- Program levels, age groups and fees (the Programs section uses a typical abacus curriculum)
- Swap the illustrations for real centre photos if available (same file paths, or update `src` in `index.html`)
